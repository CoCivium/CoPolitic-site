# CoPolitic | Public-policy research pointer

**Status, October 24, 2026: public GitHub source pointer only.**
This repository is a policy/governance-facing placeholder. A connected web domain or active publication under copolitic.org or copolitic.com is **not verified**. Its old state was a single-line scaffold; this README is an informational pointer, not a deployed website.

## Scope and boundaries

This is **not** an election office, official audit, political party or campaign, government-endorsed initiative, collector of allegations, or publication of actual election-system findings. It does not target political beliefs or infer individual votes. Public scrutiny should distinguish original sources, actual independent findings, corrections and unresolved unknowns.

Urgent voting-rights or alleged election crime concerns belong with [official reporting channels](https://www.usa.gov/voter-fraud), not a CoCivium issue or repository.

## Planned domain relation

The [CoCivium Master Plan](https://github.com/CoCivium/CoCivium/blob/main/plans/MasterPlan.md) assigns copolitic.org a policy/governance-facing candidate role and copolitic.com an alias/redirect role. That plan does **not** prove current registrar control, DNS, HTTPS, CNAME, serving or independent recipient access. Future activation requires exact owner authority, domain/hosting and source-version binding, independent browser readback, corrections and rollback.

Source code, domain identity, public service, independent AI indexing and actual civic benefit are separate evidence states.

**No crowns, no coercion, no corruption** is an aspiration and an accountability test, not an established outcome.
